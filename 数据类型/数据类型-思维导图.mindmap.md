# Rust 数据类型

## 0. 三条总规则

### 规则 1 没有隐式类型转换
- i32 与 i64 是两个类型
- 必须显式 as 或 From 或 try_from
- 没有 C 那种数值提升

### 规则 2 大小在编译期确定
- 没有运行时才知道大小的类型
- 动态大小要用引用或 Box

### 规则 3 默认类型
- 整数字面量默认 i32
- 浮点字面量默认 f64

## 1. 整数类型

### 类型清单
- 有符号 i8 i16 i32 i64 i128 isize
- 无符号 u8 u16 u32 u64 u128 usize
- isize 与 usize 跟指针同宽
- 下标与长度用 usize

### 字面量写法
- 下划线分隔 98_222
- 十六进制 0xff
- 八进制 0o77
- 二进制 0b1111_0000
- 字节字面量 b'A' 是 u8
- 类型后缀 1u64
- 科学计数 1e3

### 取值范围
- i8 是 -128 到 127
- u8 是 0 到 255
- i32 是正负 21 亿
- 用 i32 当默认选择

### 运算陷阱
- 整数除法向零截断
- 负七除二得负三
- 余数符号跟被除数
- 整数除零会 panic
- 没有幂运算符 用 pow

### 溢出三种行为
- 常量溢出是编译错误
- debug 运行时 panic 退出码 101
- release 静默回绕
- 报错 attempt to add with overflow

### 溢出处理方法
- checked_add 溢出返回 None
- wrapping_add 明确回绕
- saturating_add 饱和到边界
- overflowing_add 返回值与标志
- 金额与计数优先用 checked

### 取负也会溢出
- i32 最小值取负会 panic
- 报错 attempt to negate with overflow

## 2. 类型转换

### as 截断式转换
- 三百 i32 转 u8 得 44
- 负一 i8 转 u8 得 255
- 浮点转整数向零截断
- 只有 u8 能 as 成 char
- bool 能 as 成整数
- 整数不能 as 成 bool 报 E0054

### 浮点转整数的边界
- 超大值饱和到 i32 最大值
- NaN 转成 0
- 无穷饱和到最大值
- 不是未定义行为

### From 与 Into
- 保证不失败的转换
- 小类型到大类型才有
- 实现 From 自动获得 Into

### TryFrom 与 TryInto
- 可能失败的转换
- 返回 Result
- 跨范围转换用它

### 数字与字符串
- parse 需要知道目标类型
- to_string 数字转字符串
- format 可以补零
- from_str_radix 按进制解析
- parse 别无脑 unwrap

## 3. 浮点类型

### 只有两种
- f32 四字节约七位精度
- f64 八字节约十六位精度
- 默认是 f64
- 精确计算不要用浮点

### 比较陷阱
- 零点一加零点二不等于零点三
- 用误差范围比较
- NaN 不等于自己
- NaN 与任何数比较都是假
- 浮点除零得无穷不 panic

### 排序问题
- f64 没实现 Ord
- sort 报 E0277
- 因为存在 NaN
- 方案一 sort_by 加 partial_cmp
- 方案二 sort_by 加 total_cmp 推荐

### 常用方法
- floor 向下取整
- ceil 向上取整
- round 远离零四舍五入
- trunc 向零截断
- sqrt 与 powi
- EPSILON 最小差值

## 4. 布尔与字符

### 布尔
- 一字节
- true 与 false
- 能 as 成整数
- 整数不能 as 成布尔

### 字符
- 单引号
- 永远是四字节
- Unicode 标量值
- 能存中文与 emoji
- 转义与 Unicode 码点写法

### 字符的方法
- is_alphabetic
- is_alphanumeric
- to_digit 返回 Option
- to_ascii_uppercase 非 ASCII 原样返回
- char as u8 会截断要小心
- 要码点用 as u32

## 5. 字符串

### 两种类型分工
- String 拥有堆内存可增长
- str 是借用只读
- 参数优先用 str
- 返回值优先用 String
- 二者不能直接互相赋值

### 创建方式
- String new 与 from
- to_string 与 to_owned
- format 宏
- with_capacity 预留

### 长度陷阱
- len 是字节数
- chars count 是字符数
- 中文每个字三字节
- is_char_boundary 判断边界

### 不能下标访问
- s 零 报 E0277
- 因为 UTF-8 变长
- 替代 chars nth
- 替代 as_bytes
- 替代 get 返回 Option

### 切片必须落在字符边界
- 切在中间会 panic
- 报错 not a char boundary
- emoji 可能占四字节
- 安全写法用 get
- 或用 chars take

### 拼接与常用操作
- push 加字符
- push_str 加字符串
- 加号会移动左边
- format 推荐
- contains 与 find
- find 返回字节下标
- replace split trim
- 原始字符串不处理转义
- 字节串前缀 b

## 6. 元组与数组

### 元组
- 定长可混合类型
- 点零访问
- 解构与忽略
- 单元类型是空元组
- 单元素要加逗号
- 可以字典序比较
- 超过四个值建议用结构体

### 数组
- 类型是方括号 T 分号 N
- 长度是编译期常量
- 栈上分配
- 重复值语法
- len 是编译期常量
- 越界 panic 用 get 安全
- 切片与可变数组
- 元素 Copy 时数组也是 Copy

### 数组的两个报错
- 长度用变量报 E0435
- 长度不同是两个类型报 E0308

## 7. Vec 动态数组

### 创建
- Vec new 要标类型
- vec 宏
- 重复值语法
- collect 从迭代器
- with_capacity 预留

### 增删改
- push 与 pop 尾部
- insert 与 remove 指定位置是 O n
- extend 追加多个
- retain 就地过滤
- clear 清空
- 下标赋值

### 访问
- 下标越界 panic
- get 返回 Option 安全
- first 与 last

### 查询与变换
- contains
- position
- sum 与 max
- len 与 is_empty

### 装不同类型
- 用枚举推荐
- 或用 Box dyn Trait

### VecDeque
- 两端高效增删
- push_front 与 push_back

## 8. 集合类型

### HashMap
- 键必须实现 Hash 与 Eq
- get 安全 下标会 panic
- entry API 不存在才插入
- entry 加 or_insert 计数惯用法
- 遍历顺序不保证
- remove 返回 Option

### HashSet
- 去重与成员判断
- 从迭代器 collect

### BTreeMap 与 BTreeSet
- 按 key 有序
- keys 顺序稳定
- range 范围查询

### 选择建议
- 只查找用 HashMap
- 要有序用 BTreeMap
- 要稳定顺序输出必须排序

## 9. 结构体

### 三种形态
- 具名结构体
- 元组结构体用点零访问
- 单元结构体做标记

### 初始化
- 字段简写
- 结构体更新语法
- 字段必须写全否则 E0063
- 要默认值就实现或派生 Default

### 派生宏
- Debug 支持打印
- Clone 与 Copy
- PartialEq 与 Eq
- Hash 才能当键
- Default 默认值
- PartialOrd 与 Ord 才能排序
- Copy 要求所有字段 Copy
- 含 f64 不能 Eq 与 Hash

### 方法与关联函数
- new 无 self
- self 只读方法
- mut self 修改方法
- self 消费方法
- Self 指当前类型

### 私有性
- 字段默认私有
- 要暴露加 pub

## 10. 枚举

## 12. 常见报错速查

### 类型不匹配
- E0308 数值类型不同
- E0308 String 与 str
- E0308 数组长度不同
- E0054 整数转 bool

### 推断与常量
- E0282 需要类型标注
- E0435 数组长度不是常量
- E0609 元组下标越界
- E0063 结构体字段没写全

### trait 缺失
- E0277 没派生 Debug
- E0277 没派生 PartialEq
- E0277 f64 没有 Ord
- E0277 str 不能下标

### 递归类型
- E0072 无限大小要用 Box

### 运行时 panic
- 整数溢出 debug
- 整数除零
- 取负溢出
- 下标越界
- 哈希表键不存在
- 字符串切在字符中间

## 13. 写法注意事项

### 选对类型
- 一般整数 i32
- 下标长度 usize
- 字节数据 u8 与 Vec u8
- 浮点 f64
- 金额用整数或 Decimal
- 可能没值用 Option
- 可能失败用 Result
- 多选一用 enum

### 函数签名建议
- 参数优先借用 str 与切片
- 需要接管才按值收
- 返回优先拥有型

### 细节清单
- 浮点别用等号 用误差
- 下标优先 get
- 想清字节还是字符
- 集合预分配容量
- 与 C 交互要 repr C
- 整数除法别指望小数
- 字符与字节别混

### 避免的写法
- Vec 不预分配反复扩容
- HashMap 当有序容器
- String 存二进制
- f64 当键
- 元组返回太多值
- 无脑 unwrap 用户输入

## 14. 常见误区

### 数值
- 不会隐式提升类型
- 整数溢出不是自动变大
- 浮点除零不崩 整数才崩
- 一除二不是零点五
- 负七除二不是负四

### 字符与字符串
- char 不是一字节是四字节
- len 是字节数不是字符数
- 字符串不能下标
- 切片必须落在字符边界
- 浮点不能直接 sort

### 容器
- 数组长度必须是常量
- 长度不同是不同类型
- 结构体不写全会报错
- Vec 不能装不同类型
- 递归类型要 Box
- HashMap 顺序不稳定

### 转换
- as 不安全会截断
- 浮点等号比较不可靠
